APATHY v24 — Лёгкий аудио-бот Telegram + сайт https://awuro.sergeyhownan.workers.dev/
======================================================================================

ЧТО УЖЕ НАСТРОЕНО:
- Адрес сайта https://awuro.sergeyhownan.workers.dev/ прописан по умолчанию в main.py и .env.example.
- Бот ищет музыку лёгким async-запросом (без тяжёлой нагрузки на CPU и без мусора в SQLite)
  и забирает СТРОГО аудиопотоки (m4a <= 128 кбит/с / mp3, vcodec=none, без видео и без ffmpeg).
- По умолчанию фоновое скачивание отключено (AUTO_CACHE_TO_TG=0), стриминг идёт чанками по 32 КБ.

ЗАПУСК:
1. Загрузите файлы из apathy_tg_bot_v24.zip в корень вашего репозитория GitHub (без .env!)
   и задайте в панели хостинга переменную BOT_TOKEN (и при желании BOT_API_URL = публичный HTTPS-адрес бота).
2. На сайт https://awuro.sergeyhownan.workers.dev/ загрузите файлы из apathy_web_workers_v24.zip.
3. Если не указали BOT_API_URL в переменных окружения — просто напишите боту в Telegram:
     /setapi https://публичный-адрес-вашего-бота
4. Нажмите кнопку «🎵 Открыть плеер APATHY» в боте — сайт https://awuro.sergeyhownan.workers.dev/
   автоматически привяжется к боту и начнёт искать и включать треки только через него!
