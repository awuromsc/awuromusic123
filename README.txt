APATHY v42 — Серверная поддержка Android APK и принудительных обновлений (Force Update)
=========================================================================================

ЧТО ДОБАВЛЕНО В v42:
1. API для Android-приложения:
   - GET /api/app/version  — отдаёт последнюю версию, минимально допустимую версию, описание и ссылку на APK.
   - GET /api/app/download — раздаёт актуальный APATHY.apk напрямую (из Telegram или редиректом на GitHub).
2. Управление версиями и Force Update прямо из Telegram (только админ):
   - Отправьте файл .apk прямо боту — он сохранится автоматически.
   - /setapp 2 2 1.1.0 | Что нового — задаёт latestVersionCode, minVersionCode и описание.
     Если minVersionCode == latestVersionCode, у всех на старых версиях появится обязательный экран обновления.
   - /setapk https://... — задаёт внешнюю ссылку на APK (например, с GitHub Releases).
3. Команда /apk для пользователей — выдаёт актуальный установочный APATHY.apk прямо в чате бота.

КАК ОБНОВИТЬ:
- Замените main.py в репозитории бота на GitHub (или распакуйте apathy_tg_bot_v42.zip) и перезапустите на Bothost.
  Сайт на Cloudflare Workers обновлять не нужно.
