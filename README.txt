APATHY v37 — Закрытый доступ к «Ваши треки» по Telegram + долгоживущая сессия (180 дней)
==========================================================================================

ЧТО ДОБАВЛЕНО И ИСПРАВЛЕНО В v37:
1. Авторизация для доступа к разделу «Ваши треки»:
   - Неавторизованный пользователь не может зайти во вкладку «Ваши треки» — при нажатии приложение
     автоматически переводит его на экран входа через Telegram с подсказкой и подсветкой карточки.
   - Внутри самой вкладки «Ваши треки» также стоит защитная заглушка (даже при выходе из аккаунта).
   - Сразу после входа через Telegram приложение автоматически открывает «Ваши треки».
2. Долгоживущая сессия Telegram (не слетает каждый час):
   - В main.py введены криптографически подписанные токены (HMAC-SHA256 на базе BOT_TOKEN) сроком на 180 дней
     с автоматическим скользящим продлением раз в 7 дней — сессия остаётся активной постоянно.
   - Токен переживает перезапуски и пересборки контейнера на Bothost (даже при временном сбросе SQLite
     пользователь автоматически восстанавливается по подписи токена, без ошибки 401).
   - На сайте токен дублируется сразу в 3 хранилищах: localStorage + First-Party Cookie (180 дней) + IndexedDB,
     поэтому мобильные браузеры и WebView больше не сбрасывают вход.
   - Выход на одном устройстве больше не разлогинивает остальные ваши устройства.

КАК ОБНОВИТЬ (2 ШАГА):
1. Бот (GitHub / Bothost): замените main.py (или весь архив apathy_tg_bot_v37.zip) и перезапустите бота.
2. Сайт (Cloudflare Workers — https://awuro.sergeyhownan.workers.dev/): загрузите все 10 файлов из
   apathy_web_workers_v37.zip (версия ?v=37 и sw.js обновят кэш автоматически).
