APATHY v26 — Telegram-бот (строго .MP3) + исправленный сайт https://awuro.sergeyhownan.workers.dev/
=====================================================================================================

ЧТО ИСПРАВЛЕНО В v26:
1. Исправлен пустой экран на сайте после свайпа креста (удалён лишний закрывающий тег </div> в index.html).
2. В Dockerfile добавлен ffmpeg, а в main.py — обязательная выдача стандартного .MP3 (160 кбит/с, audio/mpeg):
   - Если трек уже настоящий MP3 (SoundCloud, Hitmo, Muzofond, Mp3Party, LightAudio) — отправляется мгновенно без конвертации.
   - Если трек пришёл в формате m4a / DASH / WebM (YouTube) — автоматически пересобирается в чистый .mp3,
     который без ошибок запускается и перематывается в Telegram и на iPhone Safari!

КАК ОБНОВИТЬ:
1. В репозиторий GitHub для бота загрузите файлы из apathy_tg_bot_v26.zip (ОБЯЗАТЕЛЬНО обновите и main.py, и Dockerfile!)
   и нажмите «Пересобрать» на хостинге, чтобы установился ffmpeg.
2. На сайт https://awuro.sergeyhownan.workers.dev/ загрузите 9 файлов из apathy_web_workers_v26.zip.
3. Проверьте в боте командой /test — строка «ffmpeg» должна показать «✅ активен (выход строго .mp3)».
