APATHY v37 — Чистый бот для пользователей + вход в «Ваши треки» + сессия на 365 дней
====================================================================================

1. Скрыты все служебные и админ-команды в Telegram-боте для обычных пользователей:
   - В /start обычным пользователям показаны только плеер, поиск и /playlists.
   - В меню команд Telegram (/) оставлены только /start и /playlists.
   - Команды /admin, /backup, /restore, /test, /list, /del, /setapi, /setstorage и cookies.txt
     доступны только администратору (автоопределение по ADMIN_ID или правам админа в STORAGE_CHAT_ID).
2. Закрыт доступ во вкладку «Ваши треки» без входа через Telegram:
   - Неавторизованный пользователь видит экран с кнопкой «Войти через Telegram» прямо внутри вкладки.
3. Долгоживущая сессия Telegram (365 дней):
   - Криптографически подписанный HMAC-токен ap2 на 1 год с автопродлением, который переживает
     перезапуски контейнера и дублируется на клиенте в localStorage + Cookie + IndexedDB.

КАК ОБНОВИТЬ:
1. Бот (GitHub / Bothost): обновите main.py (или apathy_tg_bot_v37.zip) и перезапустите бота.
2. Сайт (Cloudflare Workers): загрузите 10 файлов из apathy_web_workers_v37.zip.
