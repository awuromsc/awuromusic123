APATHY — Telegram Бот + Веб-плеер (v22)
=======================================

КАК ЗАПУСТИТЬ ЗА 3 ШАГА:
1. Создайте бота в Telegram через @BotFather -> получите BOT_TOKEN.
2. Загрузите архив apathy_telegram_bot_app.zip на ваш Python-хостинг (или VPS / ПК) и распакуйте.
3. Переименуйте .env.example в .env (или задайте переменные окружения на хостинге):
     BOT_TOKEN=ваш_токен_от_BotFather
     WEBAPP_URL=https://ваш-домен-хостинга (чтобы открывать плеер прямо в Telegram!)
4. Установите зависимости и запустите:
     pip install -r requirements.txt
     python main.py

КАК ПОЛЬЗОВАТЬСЯ:
- Сайт с плеером APATHY откроется сразу по адресу вашего хостинга (http/https).
- Перешлите боту ЛЮБУЮ песню (из других музыкальных ботов, каналов или с телефона) -> трек мгновенно появится на сайте!
- Или напишите боту название песни -> выберите вариант -> трек загрузится в Telegram и сразу станет доступен на сайте.
- Если добавить бота администратором в ваш приватный Telegram-канал и написать там /setstorage:
    * Любые песни, которые вы скидываете в канал, сами добавляются на сайт.
    * Любые песни, которые вы ищете прямо на сайте, автоматически сохраняются в этот канал и со следующего раза играют за 0.2 сек с серверов Telegram!

ЕСЛИ САЙТ ОСТАЁТСЯ НА CLOUDFLARE PAGES:
- Загрузите apathy_pages_v22_tg.zip на Cloudflare Pages.
- Откройте сайт с параметром: https://<ваш-сайт>.pages.dev/?api=https://<адрес-вашего-бота>
  (или укажите эту ссылку в WEBAPP_URL в .env — плеер запомнит адрес бота автоматически!).
