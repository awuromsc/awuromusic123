APATHY v29 — Telegram Аккаунт и облачная синхронизация личных плейлистов
========================================================================

ЧТО ДОБАВЛЕНО В v29:
1. Вход через Telegram без лишних настроек в @BotFather:
   - Внутри Telegram (кнопка «Открыть плеер APATHY»): автоматический вход по криптографической подписи Telegram WebApp.
   - В обычном браузере (Safari / Chrome на https://awuro.sergeyhownan.workers.dev/):
     Профиль -> «Войти через Telegram» -> 1 нажатие «Запустить» в боте -> аккаунт привязывается мгновенно!
2. Личные облачные плейлисты и избранное в SQLite на сервере бота:
   - Все созданные плейлисты, добавленные треки, лайки и выбранная тема автоматически синхронизируются с аккаунтом Telegram.
   - При входе с телефона, ПК или внутри Telegram загружается одна и та же ваша личная медиатека.
   - Команда /playlists в боте показывает ваши личные плейлисты и избранное.
